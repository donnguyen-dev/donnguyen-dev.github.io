Picklist Doctor

Understand why a picklist value isn’t available.

A read-only diagnostic tool that helps Salesforce administrators inspect picklist configuration, compare record types, and prepare a clear report of what they find.

The initial build is running in a development org. Public installation and marketplace availability are not yet available.

01

Inspect configuration

Explore accessible fields, values, and record types in the current user’s context.

02

Compare record types

See differences in available values, defaults, and controlling-value restrictions.

03

Share the findings

Copy a diagnostic report that distinguishes observed configuration from unknowns.

How we build

Useful by design.
Honest about the limits.

We favour focused tools, clear explanations, and careful access to data. Picklist Doctor reads configuration without changing CRM records. When the available metadata cannot explain a result, it says so.
